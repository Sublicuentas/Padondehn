PA' DÓNDE HN — VERSIÓN DE LANZAMIENTO

1. Abra firebase-config.js y pegue la configuración de su aplicación web Firebase.
2. Escriba su correo en PADONDE_ADMIN_EMAIL.
3. En Firebase Authentication active Correo/contraseña.
4. Cree Firestore.
5. Suba esta carpeta completa a un repositorio y publíquela en Vercel.
6. Regístrese con el correo administrador; aparecerá el botón de ajustes para cargar y editar contenido.

La aplicación también funciona sin Firebase en modo demostración local.
Los precios, horarios y promociones cambian: verifique cada ficha antes de publicarla.
